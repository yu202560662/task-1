# 一、面向对象三大特性

C++ 面向对象思想有三大特性：**封装、继承、多态**。

后续课程会逐一详细讲解，先记住这三个词即可。

# 二、类与对象

## 1. 基本概念

* C++ 中认为**万事万物都可以称为对象**，如手机、鼠标、键盘、显示器等。
* 对象有**属性**和**行为**，例如人（张三）有姓名、年龄、身高、体重等属性，有走、跑、跳等行为。
* 车也有属性（轮胎、方向盘、车灯）和行为（载人、放音乐、放空调）。
* 把所有具有相同特性的对象**抽象为一类**，如"人"抽象为"人类"，"车"抽象为"车类"。

## 2. 类的设计

* 使用关键字 `class` 定义类，后面紧跟类名。
* 类中包含**属性**（用变量表示）和**行为**（用函数表示）。

## 3. 实例化

* 通过一个类创建一个具体对象的过程叫**实例化**。
* 通过对象使用 `.` 访问其属性和行为。

# 三、封装

封装是面向对象三大特性之一，有**两层含义**：

1. 将属性和行为作为一个整体来表现生活中的事物（对象）。
2. 对属性和行为加权限控制（本节课先不深入，下节课讲解）。

# 四、案例：设计圆类求周长

## 1. 需求分析

* 设计一个圆类，求圆的周长。
* 公式：**周长 = 2 × π × 半径**（π ≈ 3.14）。

## 2. 设计思路

* 半径作为圆的属性（直径、圆心本案例不需要）。
* π 写为常量 `const double PI = 3.14`。

## 3. 代码结构

```cpp
class Circle {
public:
    int m_R;                        // 半径属性
    double calculateCircumference() // 行为：获取周长
    {
        return 2 * 3.14 * m_R;
    }
};
```

## 4. 创建对象

```cpp
Circle c;                                     // 通过类创建对象
c.m_R = 10;                                   // 给属性赋值
cout << c.calculateCircumference() << endl;   // 输出周长 62.8
```

# 五、案例：设计学生类

## 1. 需求

* 设计学生类，属性有姓名和学号，可赋值并显示学生信息。

## 2. 代码结构

```cpp
class Student {
public:
    string m_Name;              // 姓名
    int m_Id;                   // 学号

    void showStudent()          // 显示学生信息
    {
        cout << m_Name << m_Id << endl;
    }
};
```

## 3. 创建对象

```cpp
Student s1;
s1.m_Name = "张三";
s1.m_Id = 1;
s1.showStudent();   // 输出张三 1
```

## 4. 通过行为给属性赋值

```cpp
void setName(string name)
{
    m_Name = name;
}

s1.setName("张三");   // 通过函数给属性赋值
```

# 六、专业术语

* 类中的属性和行为统称为**成员**。
* 属性也叫**成员属性 / 成员变量**。
* 行为也叫**成员函数 / 成员方法**。

# 七、访问权限

访问权限有三种：

| 权限   | 英文          | 类内访问 | 类外访问 |
| ---- | ----------- | ---- | ---- |
| 公共权限 | `public`    | ✅    | ✅    |
| 保护权限 | `protected` | ✅    | ❌    |
| 私有权限 | `private`   | ✅    | ❌    |

* **保护权限**：父子关系中，儿子可以访问父亲中的保护内容（如父亲的车）。
* **私有权限**：父亲不想让儿子知道的内容（如银行卡密码）。

# 八、struct 与 class 的区别

* **唯一区别：默认访问权限不同。**
* `struct` 默认权限是 `public`（公共）。
* `class` 默认权限是 `private`（私有）。

# 九、成员属性设置为私有

企业开发中通常将成员属性私有化，有**两点好处**：

1. 自己控制读写权限。
2. 写权限时验证数据有效性。

## 案例：Person 类

* **姓名**：可读可写（提供 set/get 方法）。
* **年龄**：只读（只提供 get 方法，不提供 set）。
* **偶像**：只写（只提供 set 方法，不提供 get）。

```cpp
class Person {
private:
    string m_Name;      // 姓名
    int m_Age;          // 年龄
    string m_Idol;      // 偶像

public:
    // 姓名：可读可写
    void setName(string name) { m_Name = name; }
    string getName() { return m_Name; }

    // 年龄：只读
    int getAge() { return m_Age; }

    // 偶像：只写
    void setIdol(string idol) { m_Idol = idol; }
};
```
