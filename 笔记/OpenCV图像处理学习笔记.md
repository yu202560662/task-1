# OpenCV 图像处理学习笔记

---

## 第一部分：图像基础概念

### 1. 图像的构成

- 图像由像素（pixels）组成，可以想象为一个盒子阵列，每个盒子可填充或留空
- 例如要显示字母"NO3"，可通过给部分盒子上色来形成形状
- 黑色盒子记为 0，白色盒子记为 1

### 2. 图像分辨率

- 示例为 10×10 的盒子阵列，需要更多细节时可增加盒子数量
- 常见分辨率标准：
  - VGA：640×480
  - HD：1280×720
  - 分辨率越高，像素数量越多，图像越清晰

### 3. 图像类型

- **二值图像（Binary Image）**：仅包含黑白两色（0 和 1）
- **灰度图像（Grayscale Image）**：使用 8 位值，分辨率达 256 级
  - 0 表示黑色，255 表示白色
  - 黑白之间共有 254 种灰色调
- **彩色图像（RGB）**：由红、绿、蓝三张灰度图像叠加而成
  - 彩色 VGA 图像尺寸为 640×480×3
  - 注意：OpenCV 默认使用 **BGR** 顺序，不是 RGB

### 4. 灰度转换公式

OpenCV 做 RGB/BGR 转灰度时，默认采用加权公式（权重来自人眼对绿色最敏感、红色次之、蓝色最弱的视觉特性）：

```
Gray = 0.299 × R + 0.587 × G + 0.114 × B
```

在 OpenCV C++ 中通常写作：

```cpp
cv::cvtColor(image, grayImage, cv::COLOR_BGR2GRAY);
```

> 注意：这里不是简单求平均，也不是只取某一个通道。

## 第二部分：OpenCV 开发环境搭建（C++）

### 第 1 步：下载 Visual Studio

- 下载社区版（Community Version）
- 安装时选择"使用 C++ 进行桌面开发"（Desktop development with C++）
- 如果使用 VS2022，建议确认安装了 MSVC v143 工具和 Windows SDK

### 第 2 步：下载 OpenCV

- 点击课程网站提供的链接，进入 GitHub 页面
- 点击 Releases，下载 exe 可执行文件并安装
- 安装路径建议放在 D 盘（若装在 C 盘需修改对应盘符）
- 解压到不含中文的路径，例如：`D:\OpenCV\4.10.0`

### 第 3 步：配置环境变量

- 将 OpenCV 的 bin 路径添加到系统环境变量 Path 中
  - 例如：`D:\OpenCV\4.10.0\build\x64\vc16\bin`
- 配置完成后需重启电脑（或至少重启 Visual Studio）

### 第 4 步：创建 Visual Studio 项目

- 新建 C++ 空项目，命名为 OpenCV Course
- 将平台目标（Platform Target）设置为 **x64**

### 第 5 步：配置项目属性

- 进入项目属性 → VC++ 目录
  - 添加包含目录（Include Directories）：`...\build\include`
  - 添加库目录（Library Directories）：`...\build\x64\vc16\lib`
- 进入链接器 → 输入，添加附加依赖项
  - Debug 版本：`opencv_world4100d.lib`（带 d 后缀）
  - Release 版本：`opencv_world4100.lib`（不带 d 后缀）
  - 该文件位于 OpenCV 安装目录的 bin 文件夹中
  - 具体文件名要和你的 OpenCV 版本一致

### 常见报错提示

| 报错现象 | 可能原因 | 解决方法 |
|---|---|---|
| 找不到头文件 `opencv2/opencv.hpp` | 包含目录未正确配置 | 检查 VC++ 包含目录设置 |
| 链接错误 | 库目录或依赖项不匹配 | 检查库目录和附加依赖项是否匹配 Debug/Release |
| 运行时报缺少 .dll | 环境变量 Path 未配置 | 检查环境变量 Path 是否包含 OpenCV 的 bin 目录 |
| 图像读取失败（无报错但画面空白） | `imread` 返回空 Mat | 用 `img.empty()` 判断读取是否成功 |

## 第三部分：图像、视频与摄像头导入（C++）

### 一、导入图像（Image）

1. 使用 `Mat` 数据类型读取图像，`Mat` 是 OpenCV 引入的用于处理所有图像的数据类型（本质是一个矩阵）
2. 通过路径读取图像，并给图像命名（如 `image`）
3. 显示图像后会自动关闭，因为没有设置延迟，因此需要添加延迟函数：
   - `waitKey(0)` 表示无限等待，直到按下关闭按钮
4. 运行后即可显示测试图像

**健壮性建议：** `imread` 读图失败时不会报错，而是返回空的 `Mat`，所以每次读图后都应该用 `img.empty()` 检查一下，否则后续操作会直接崩溃。

### 二、导入视频（Video）

1. 视频本质上是一系列图像的集合（帧），需要遍历所有帧并逐帧捕获显示
2. 使用 `while` 循环（`while(true)`）持续读取帧
3. 创建 `VideoCapture` 对象（命名为 `cap`），并定义视频路径
4. 路径改为视频文件（如 `test_video.mp4`）
5. 在循环外声明 `Mat image` 变量，循环内从对象中逐帧读取图像并存储
6. 显示图像时设置延迟（如 1 毫秒），而非无限等待
7. 可通过调整延迟值（如 20 毫秒）控制播放速度
8. 视频播放结束后会报错（因为没有更多帧可显示）

**健壮性建议：**

- 可以在循环里加一个判空检查来优雅退出：

```cpp
cap >> frame;
if (frame.empty()) break;
```

- `waitKey` 不仅控制延迟，还会返回按键的 ASCII 码。可以用它来实现"按 q 退出"：

```cpp
if (waitKey(1) == 'q') break;
```

- 注意视频/摄像头场景用 `waitKey(1)` 而非 `waitKey(0)`，后者会无限等待导致画面卡住

### 三、导入摄像头（Webcam）

1. 思路与视频导入类似，复制视频代码并注释掉
2. 关键区别：不定义路径，而是传入摄像头 ID 号
3. 单摄像头通常用 ID `0`；多摄像头时按需选择（如 ID `1`）
4. 延迟需调整为合适值（如 1 毫秒），避免播放过慢
5. 运行后可实时显示摄像头画面

**健壮性建议：** 摄像头场景也建议加上 `cap.isOpened()` 检查，确认设备是否成功打开。

### 四、工程管理技巧（多章节文件）

1. 一个工程中只能有一个 `main` 函数，不能同时运行多个含 `main` 的文件
2. 解决方案：右键点击不需要的章节文件 → "Exclude from Project"（从工程中排除）
3. 需要时可通过 "Show All Files" 重新显示，再 "Include" 恢复
4. 任意时刻只运行一个章节文件

### 五、图像处理基础函数（Chapter 2）

1. 新建 `chapter2` 文件，复制图像代码并注释掉视频/摄像头代码
2. 灰度转换：使用 `cvtColor` 函数，参数包括输入图像、输出图像（如 `imageGray`）及转换类型（如 `COLOR_BGR2GRAY`）

```cpp
cv::cvtColor(image, imageGray, cv::COLOR_BGR2GRAY);
```

> **cvtColor 的内存行为：** C++ 中 `cvtColor(image, gray_image, COLOR_BGR2GRAY)` 会为 `gray_image` 分配独立的内存空间，相当于"转换 + 深拷贝"，修改灰度图不会影响原图。

## 第四部分：图像处理进阶（第 2 章）

### 一、项目准备

- 将第 1 章的代码全部复制到第 2 章中
- 使用图片而非视频/摄像头，因此移除所有视频和摄像头相关代码，取消注释图片代码
- 使用同一张测试图片
- 技巧：可右键排除不需要的章节，确保每次只运行一个章节

### 二、图像读取与灰度转换

**核心函数：** `cvtColor`

```python
imageGray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
```

**要点：**

- OpenCV 使用 BGR 约定（蓝、绿、红），而非 RGB
- 转换目标：`COLOR_BGR2GRAY`（BGR 转灰度）
- 需先定义目标图像变量（如 `imageGray`），否则会报错

### 三、高斯模糊（GaussianBlur）

**核心函数：** `GaussianBlur`

```python
imageBlur = cv2.GaussianBlur(imageGray, (7, 7), 5, 0)
```

**参数说明：**

- **核大小（Kernel Size）：** 如 7×7（越大模糊越明显）
- **sigmaX / sigmaY：** 可留空（0, 0）或加值（如 5, 0）
  - 当 sigmaY 设为 0 时，OpenCV 会自动让它等于 sigmaX，所以实际是 (5, 5)
  - 如果想完全由核大小决定模糊程度，两个 sigma 都设为 0 即可
- 核越小（如 3×3），模糊效果越细微

**Python 与 C++ 写法差异：**

| 对比项 | Python | C++ |
|---|---|---|
| 目标图像位置 | 写在函数外部（`imageGray = cv2.cvtColor(...)`） | 写在函数内部（传引用方式） |
| 本质区别 | 返回值方式（函数返回新的 ndarray） | 传引用方式（函数内部修改传入的 Mat 对象） |

### 四、边缘检测（预告）

- 完成模糊后，下一步学习边缘检测
- 最常用的边缘检测器：**Canny 边缘检测器**
- Canny 检测器通常需要先做高斯模糊来降噪，因此标准流程为：**灰度 → 模糊 → 边缘检测**

## 第五部分：关键要点总结

### 图像基础

| 概念 | 要点 |
|---|---|
| 图像本质 | 由像素阵列组成，黑白用 0/1 表示 |
| 分辨率 | VGA = 640×480，HD = 1280×720 |
| 图像类型 | 二值图 → 灰度图 → RGB 彩色图 |
| 灰度级 | 8 位 = 256 级（0 黑 ~ 255 白） |
| 通道顺序 | OpenCV 默认 BGR，非 RGB |

### 环境搭建

| 步骤 | 内容 |
|---|---|
| 1 | 安装 Visual Studio（选择 C++ 桌面开发） |
| 2 | 下载并安装 OpenCV |
| 3 | 配置环境变量（Path 添加 bin 目录） |
| 4 | 创建 VS 项目（平台选 x64） |
| 5 | 配置项目属性（包含目录、库目录、附加依赖项） |

### 图像/视频/摄像头导入核心区别

| 数据源 | 读取方式 | 关键区别 |
|---|---|---|
| 图像 | `imread(路径)` | 一次性读取 |
| 视频 | `VideoCapture(路径)` + 循环逐帧 | 需 `waitKey` 控制速度，需判空退出 |
| 摄像头 | `VideoCapture(ID)` + 循环逐帧 | 不传路径传设备 ID，需 `isOpened()` 检查 |

### 图像处理流程

```
原始图像 → 灰度转换(cvtColor) → 高斯模糊(GaussianBlur) → 边缘检测(Canny)
```
